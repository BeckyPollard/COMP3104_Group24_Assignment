DevOps Course (COMP 3104)

COMP 3104 teaches the practices a DevOps engineer brings to the
workplace to improve productivity. Students analyze different DevOps
implementations and do hands-on work with industry-standard tools.

Topics Covered

The course covers Bash and the command line, Git and GitHub, CI/CD with
tools like GitHub Actions, Travis CI, and Jenkins, cloud infrastructure,
test automation and code quality with SonarQube, and containerization
with Docker.

Career Relevance

The course also prepares students for DevOps roles by covering market
demand, required skills, and certification opportunities.
